## Bug encontrado e corrigido: `'auth'` ausente em `DEFAULT_THROTTLE_RATES` no settings de teste [P2]

- **Tipo:** P2 — Regressão de infraestrutura de testes: dois testes P1 de segurança
  (`TestOTPViewInfoDisclosure`) falhavam com `ImproperlyConfigured: No default throttle rate
  set for 'auth' scope` toda vez que a suíte era executada, pois `WhatsAppAuthThrottle`
  (`scope = 'auth'`) não encontrava a taxa correspondente em
  `config/settings/test_serializer.py`.

- **Contexto:** `apps/core/auth/views.py` define `WhatsAppAuthThrottle(AnonRateThrottle)`
  com `scope = 'auth'`. O DRF chama `get_rate()` dentro de `__init__` antes de qualquer
  lógica de view — se o escopo não existe nas settings, levanta `ImproperlyConfigured` e a
  view nunca é executada, mesmo com `allow_request` patcheado. Os testes afetados eram
  justamente os que verificam se `POST /api/v1/auth/whatsapp/send/` e
  `POST /api/v1/auth/whatsapp/resend/` não expõem mensagens internas de erro na resposta
  HTTP (info-disclosure P1). Com esses testes sempre em erro, qualquer regressão de
  segurança nesses endpoints passaria despercebida.

- **Causa raiz:** `config/settings/base.py` declara `'auth': '10/minute'` (e também
  `'public_read'` e `'lead_create'`) mas `config/settings/test_serializer.py` nunca
  importa nem herda de `base.py` — ele define o `REST_FRAMEWORK` dict do zero, sem incluir
  os escopos adicionados depois da criação do arquivo.

- **Arquivo corrigido (1):** `config/settings/test_serializer.py`
  - Adicionados à `DEFAULT_THROTTLE_RATES`:
    - `'auth': '10/minute'` — espelha `base.py`; desbloqueia os 2 testes de segurança
    - `'public_read': '300/minute'` — evita falha silenciosa caso testes de catálogo público
      sejam adicionados ao módulo
    - `'lead_create': '10/hour'` — completa o set de base.py

- **Testes (24 SimpleTestCase)** em `apps/core/tests/test_otp_whatsapp_contract.py`:
  - **Antes:** 22/24 PASS, 2 ERROR (`ImproperlyConfigured`)
  - **Depois:** 24/24 PASS

  Os 2 testes desbloqueados:
  - `test_send_view_hides_whatsapp_auth_error_details` — `/send/` não vaza host/detalhe interno
  - `test_resend_view_hides_whatsapp_auth_error_details` — `/resend/` não vaza host/detalhe interno
