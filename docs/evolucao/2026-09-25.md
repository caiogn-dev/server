## Bug encontrado e corrigido: comparação direta de `access_token` em dois endpoints mobile [P1]

- **Tipo:** P1 — timing attack contra `access_token` de pedido em endpoints sem
  autenticação (`permission_classes = []`).

- **Arquivos corrigidos (1):** `apps/stores/api/webhooks.py`

- **Views afetadas (2):**

  1. `PaymentStatusView.get()` — `GET /api/v1/mobile/orders/{order_id}/payment-status/`
  2. `CustomerOrderDetailView.get()` — `GET /api/v1/mobile/orders/{order_id}/`

- **Problema:** ambas as views verificavam o token de acesso do pedido com o
  operador Python `==`:
  ```python
  has_valid_token = token and order.access_token and token == order.access_token
  ```
  Comparações de strings em Python terminam ao primeiro caractere diferente;
  o tempo de resposta varia com o comprimento do prefixo comum. Um atacante que
  conheça o `order_id` (UUID exposto no link de confirmação do pedido) pode
  montar um ataque de timing para adivinhar o `access_token` caractere a
  caractere, sem limite de tentativas além do rate limit.

  O padrão foi corrigido inúmeras vezes nesta base antes
  (`fix/token-timing-attack`, `fix/security-timing-attack-tokens`,
  `fix/messenger-token-timing-attack`), mas esses dois endpoints foram
  introduzidos depois do último sweep.

- **Correção:** `import hmac` no topo do módulo; ambos os comparadores trocados por:
  ```python
  has_valid_token = bool(
      token and order.access_token
      and hmac.compare_digest(str(token), str(order.access_token))
  )
  ```
  `hmac.compare_digest` compara em tempo constante; os `str()` garantem que um
  token `None` ainda falha antes da chamada (curto-circuito explícito na primeira
  condição).

- **Testes:** 4 `SimpleTestCase` novos em
  `apps/stores/tests/test_order_token_timing_attack.py` (RED→GREEN):
  - `PaymentStatusViewTimingTest.test_usa_compare_digest` — view usa `compare_digest`
  - `PaymentStatusViewTimingTest.test_nao_usa_comparacao_direta` — `==` ausente
  - `CustomerOrderDetailViewTimingTest.test_usa_compare_digest` — idem
  - `CustomerOrderDetailViewTimingTest.test_nao_usa_comparacao_direta` — idem
