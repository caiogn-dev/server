ENDPOINT SUMMARY
================================================================================

ENDPOINT 1: LIST COMBOS
─────────────────────
Route: GET /api/v1/stores/{store_slug}/combos/
Name: combo-list
Auth: Not required
Features:
  - Pagination (default: 20 items/page, max: 100)
  - Filter by is_active (true/false)
  - Order by sort_order and name
Returns: Paginated list of combos with basic info

ENDPOINT 2: GET COMBO DETAILS
──────────────────────────────
Route: GET /api/v1/stores/{store_slug}/combos/{combo_id}/
Name: combo-detail
Auth: Not required
Features:
  - UUID validation for combo_id
  - Tenant isolation (store_slug matching)
  - Includes groups with variants and selection rules
Returns: Full combo details with groups and variants

ENDPOINT 3: ADD COMBO TO CART
──────────────────────────────
Route: POST /api/v1/stores/{store_slug}/cart/add-combo/
Name: add-combo-to-cart
Auth: Not required (supports guest + authenticated users)
Features:
  - Request validation (combo_id, quantity, selections)
  - ComboSelectionValidator integration
  - Automatic session management
  - Atomic transaction support
  - Stock validation (if tracked)
Requires:
  - combo_id (UUID)
  - quantity (int, ≥ 1)
  - selections (dict of group_id → list of variant_ids)
Returns: Cart summary with updated items

      "quantity": 1,
      "selections": {
        "group-uuid": ["variant-uuid"]
      }
    }'
